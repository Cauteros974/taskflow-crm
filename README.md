# TaskFlow CRM

TaskFlow CRM is a React-based dashboard application for managing tasks, clients, projects, and team workload.

The project is built as a small CRM system with task tracking, Kanban workflow, task details, comments, activity history, project progress calculation, team assignment, and local data persistence.

## Features

- Dashboard with general statistics
- Task management
- Create, edit, and delete tasks
- Task details page
- Task comments
- Kanban board with drag-and-drop
- Client management
- Project management
- Automatic project progress calculation
- Team page
- Assign team members to tasks
- Team workload calculation
- Activity history
- Import and export data as JSON
- LocalStorage data persistence

## Tech Stack

- React
- Vite
- Redux Toolkit
- React Router
- Material UI
- Ant Design
- dnd-kit
- Day.js
- LocalStorage

## Pages

The application includes the following pages:

- Dashboard
- Tasks
- Task details
- Clients
- Projects
- Kanban
- Team
- Activity history

## Dashboard

The dashboard shows the main application statistics:

- Total tasks
- Tasks in progress
- Tasks under review
- Critical tasks
- Total clients
- Total projects
- Task completion progress
- Upcoming tasks
- Project progress
- Team workload

## Tasks

The tasks page allows users to manage all tasks in the system.

Available actions:

- Create a new task
- Edit an existing task
- Delete a task
- Filter tasks by status and priority
- Search tasks by title
- Open a detailed task page

Each task can include:

- Title
- Description
- Status
- Priority
- Client
- Project
- Assignee
- Deadline
- Comments

## Kanban Board

The Kanban board allows users to move tasks between statuses using drag-and-drop.
